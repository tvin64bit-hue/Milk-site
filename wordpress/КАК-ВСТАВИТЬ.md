# Лендинг кафе «Милк» для WordPress

Страница собрана обычными блоками конструктора — обложка, колонки, кнопки.
Никаких плагинов и своего кода не нужно, работает на бесплатном плане.

## Порядок действий

**1. Загрузите картинки.**
Консоль → Медиафайлы → Добавить новый. Перетащите все шесть файлов из папки
`kartinki`. После загрузки откройте каждый и скопируйте его адрес — он
понадобится на шаге 3.

**2. Создайте страницу и вставьте разметку.**
Страницы → Добавить новую. В правом верхнем углу нажмите ⋮ (три точки) →
**Редактор кода**. Скопируйте всё содержимое `lending-dlya-vstavki.html`
и вставьте в поле. Затем тем же меню вернитесь в **Визуальный редактор** —
страница соберётся из блоков.

**3. Подставьте картинки.**
В разметке шесть пометок, каждую замените адресом соответствующего файла:

| Пометка | Файл |
|---|---|
| `ЗАМЕНИТЬ-НА-ФОН` | `1-fon-pervogo-ekrana.jpg` |
| `ЗАМЕНИТЬ-НА-ЗАЛ` | `6-zal-neon.jpg` |
| `ЗАМЕНИТЬ-НА-ШАКШУКУ` | `2-shakshuka.jpg` |
| `ЗАМЕНИТЬ-НА-СЕТ` | `3-set-hit.jpg` |
| `ЗАМЕНИТЬ-НА-ПИЦЦУ` | `4-picca-pepperoni.jpg` |
| `ЗАМЕНИТЬ-НА-ЛАТТЕ` | `5-latte-lavanda.jpg` |

Проще всего заменить их прямо в текстовом файле до вставки — тогда шаг 2
делается один раз и картинки встанут сразу.

Если менять адреса не хочется: вставьте разметку как есть, потом в
визуальном редакторе щёлкните по каждой картинке и выберите файл из
медиатеки кнопкой «Заменить».

**4. Сделайте страницу главной.**
Настройки → Чтение → «На главной странице отображать» → Статическую
страницу → выберите созданную.

## Что на странице

1. Первый экран: акварельный фон, заголовок «Место, где хорошо», две кнопки.
2. О кафе: фотография зала и три абзаца.
3. Меню: четыре позиции — Шакшука, Сет «Хит №1», Пицца «Пепперони», Латте
   с сырной пенкой «Лаванда». Цены и составы взяты из `menu.json`.
4. «Заказать просто»: три шага.
5. Контакты на тёмном фоне: телефон, адрес, режим работы, кнопка звонка.

## Цвета

Заданы прямо в блоках, от темы не зависят:

| Где | Цвет |
|---|---|
| Основной фон | `#F8EEE4` |
| Фон чередующихся секций | `#F9E4DA` |
| Текст и заголовки | `#3D2B1C` |
| Состав, вес, второстепенное | `#78644E` |
| Кнопки и цены | `#C85111` |
| Тёмная секция контактов | `#5F3515` |

## Шрифты

Страница использует шрифты темы. Чтобы приблизиться к основному сайту,
в Внешний вид → Редактор → Стили → Шрифты выберите заголовкам **Rubik**,
тексту — **Onest** или любой близкий гротеск.

## Чего здесь нет

Ни форм отправки, ни корзины, ни онлайн-заказа — по требованию ТЗ заказ
принимается только звонком. Кнопки «Заказать по телефону» и «Позвонить»
ведут на `tel:+79613625943` и на телефоне сразу набирают номер.
