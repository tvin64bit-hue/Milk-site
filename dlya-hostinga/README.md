# Файлы для хостинга

Здесь лежит то, что кладётся **не** в папку сайта, а рядом с ней. В архив
`npm run zip` эта папка не попадает.

## `.htaccess` — корень домена

Кладётся в `public_html`, то есть на уровень выше `milk-site`. Уводит весь
домен на https, включая все подпапки с демо-сайтами.

Почему корень, а не `sayt/.htaccess`: правило должно действовать на весь
домен, а не только на кафе.

Почему в нём `RewriteOptions InheritDownBefore`: набор правил `mod_rewrite`
в дочерней папке по умолчанию не дополняет родительский, а полностью его
заменяет. У `/milk-site` свой `.htaccess` с `RewriteEngine On` — без этой
директивы корневое правило внутри него просто не работает. Проверено:
без неё запросы к `/milk-site/*` уходили по http, с ней — уводятся на https.

`InheritDownBefore` требует Apache 2.4.8 или новее.
