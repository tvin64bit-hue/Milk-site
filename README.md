# Сайт кафе «Милк»

Ознакомительный сайт кафе в Благовещенске. Заказы онлайн не принимаются —
только звонок по телефону.

Эта инструкция написана для человека, который не программист. Все действия
делаются в браузере, на сайте GitHub. Ничего устанавливать не нужно.

---

## Главное, что нужно знать

Всё меню — 91 позиция, цены, составы, вес — лежит в одном файле **`menu.json`**
в корне проекта. Больше цены нигде не записаны. Поменяли в этом файле —
поменялось на всём сайте.

После любой правки сайт пересобирается **сам, автоматически**, за 2–3 минуты.
Ничего дополнительно нажимать не надо.

---

## Как поменять цену

1. Откройте файл `menu.json` на GitHub.
2. Нажмите карандаш «Edit this file» в правом верхнем углу.
3. Найдите нужное блюдо. Проще всего поиском: нажмите `Ctrl+F` (на Маке `⌘+F`)
   и введите название, например `Шакшука`.
4. Вы увидите запись блюда:

   ```json
   {
     "id": "shakshuka",
     "name": "Шакшука",
     "price": 390,
     ...
   }
   ```

5. Поменяйте число после `"price":`. **Только число**, без пробелов, без знака ₽
   и без кавычек. Правильно: `"price": 420`. Неправильно: `"price": "420 ₽"`.
6. Внизу страницы нажмите зелёную кнопку **Commit changes**.

Через 2–3 минуты новая цена будет на сайте.

### Зачёркнутая старая цена

Поле `"oldPrice"` — это цена, которая показывается зачёркнутой рядом с новой.
Так сделано у сетов.

- Чтобы показать зачёркнутую цену: `"oldPrice": 1520`
- Чтобы убрать её: `"oldPrice": null` (слово `null` пишется без кавычек)

Старая цена должна быть **больше** новой, иначе зачёркивание выглядит странно.

## Как добавить блюдо

1. Откройте `menu.json`, нажмите карандаш.
2. Найдите блюдо из той же категории, куда добавляете новое.
3. Скопируйте его запись целиком — от `{` до `}` — и вставьте следом,
   не забыв запятую между записями.
4. Поменяйте значения. Что означает каждое поле:

| Поле | Что писать | Пример |
|---|---|---|
| `id` | Латинские строчные буквы, цифры и дефис. Это адрес страницы блюда и имя файла фотографии. У каждого блюда свой, повторяться нельзя | `"syrniki-s-yagodami"` |
| `category` | Категория. Список — в начале файла, в разделе `categories` | `"zavtraki"` |
| `name` | Название так, как оно должно быть на сайте | `"Сырники с ягодами"` |
| `description` | Состав или описание одной строкой | `"Сырники, свежие ягоды и сметана"` |
| `weight` | Вес или объём. Если не нужен — оставьте пустые кавычки `""` | `"270 г"` |
| `price` | Цена числом, без пробелов и ₽ | `420` |
| `oldPrice` | Зачёркнутая цена числом или `null` | `null` |
| `image` | Имя файла фотографии или `null`, если фотографии нет | `"syrniki-s-yagodami.webp"` |
| `crop` | Как обрезать фото под квадрат: `"center"` для обычного снимка, `"top"` для брендированной карточки с подписью внизу | `"center"` |
| `badges` | Метки. Пустой список `[]`, если меток нет | `["hit"]` |
| `available` | `true` — блюдо есть, `false` — нет в наличии | `true` |

Какие бывают метки:

- `"hit"` — оранжевая метка «Хит»
- `"detskoe"` — кофейная метка «Детское»
- `"ostroe"` — красная метка «Острое»
- `"dobavka"` — метка «Добавка», цена выводится с плюсом: `+70 ₽`

5. Нажмите **Commit changes**.

Страница нового блюда появится сама, по адресу `/menu/<id>`. Добавлять её
куда-то отдельно не нужно — она сразу попадёт и в каталог, и в карту сайта.

**Если что-то заполнено неправильно**, сборка остановится и напишет по-русски,
что не так и в какой позиции. Сайт при этом продолжит работать в старом виде —
сломать его правкой нельзя.

## Как заменить или добавить фотографию

Фотографии готовятся автоматически: обрезаются под квадрат, сжимаются,
переводятся в современный формат. Вам нужно только положить исходник.

1. Откройте папку `Referens/Menu` на GitHub.
2. Нажмите **Add file → Upload files** и перетащите снимок.
3. Назовите файл так же, как называется блюдо в меню — например
   `Сырники с ягодами - купить за 420 руб. на ВК Маркет.jpeg`.
   Проще всего скопировать имя соседнего файла и поменять в нём название и цену.
4. Нажмите **Commit changes**.
5. Убедитесь, что в `menu.json` у этого блюда в поле `image` написано имя
   вида `"syrniki-s-yagodami.webp"` — то же, что в поле `id`, но с `.webp`.

Требования к снимку: чем больше, тем лучше, минимум 540 пикселей по короткой
стороне. Формат JPEG.

Если фотографии нет совсем — напишите в `image` значение `null`. Вместо снимка
покажется фирменная заглушка, а само блюдо останется в каталоге.

---

## Как поменять дату актуальности цен

В самом начале `menu.json` есть строка:

```json
"updated": "[ЗАПОЛНИТЬ дату]",
```

Впишите дату словами, например `"29 августа 2026"`. Она показывается подписью
внизу каталога.

## Как пересобрать сайт

Обычно ничего делать не нужно: сайт пересобирается сам после каждой правки.

Если хочется запустить сборку вручную — откройте вкладку **Actions**,
выберите слева «Сборка и публикация сайта» и нажмите **Run workflow**.

Посмотреть, как идёт сборка, можно там же. Зелёная галочка — всё хорошо,
красный крестик — что-то не так, откройте и прочитайте сообщение.

---

## Что осталось заполнить

В вёрстке пометками `[ЗАПОЛНИТЬ]` отмечены места, куда нужны данные владельца:

- **дата актуальности цен** — в `menu.json`, поле `updated`. Сейчас там стоит `[ЗАПОЛНИТЬ дату]`, и эта пометка видна на сайте под каталогом;
- **стоимость доставки при заказе меньше 1200 ₽.** Сайт сейчас говорит только «при заказе от 1200 ₽ — бесплатно» и о цене ниже порога умалчивает. Если хотите её назвать — скажите сумму;
- **идентификатор Яндекс.Метрики**, если нужна аналитика. Место под счётчик готово в макете, сам счётчик не подключён;
- **проверить фразу «каждую готовим с утра»** в блоке про завтраки: если завтраки подаются только до определённого часа, текст надо поправить и подставить время.

Координаты кафе владелец уже дал, они в `src/lib/kafe.ts` и в микроразметке.

### Фотографии

- **Три позиции без снимка вовсе** — «Сет „Горячий“», «Калифорния с креветкой», «С креветкой темпура». Вместо фото стоит фирменная заглушка;
- **десять кадров на пересъёмку** — чужая съёмка на чёрном и чисто-белом фоне, список в `TZ-prilozhenie-foto.md`, печатает `node scripts/otchet-fon.mjs`.

## Для разработчика

```bash
npm install          # установка зависимостей
npm run images       # подготовка изображений из Referens в public/images
npm run dev          # локальный сервер разработки
npm run build        # сборка статики в dist/
npm run preview      # просмотр собранной статики
npm run check:menu   # проверка menu.json без сборки
npm run check:verstka # прокрутка и выход элементов за границы на всех ширинах
npm run check:seo    # заголовки, описания, alt, микроразметка
npm run check:fon    # читаемость текста на фоне первого экрана
npm run check        # все три проверки подряд
```

Проверки вёрстки и SEO работают по запущенному `npm run preview`.

Стек: Astro в режиме статической генерации, sharp для изображений, обычный CSS
с переменными в `src/styles/tokens.css`. Серверной части нет.

Папка `Referens/` — исходные материалы, только для чтения. Обработанные
изображения складываются в `public/images/` и в репозиторий не коммитятся:
они пересобираются на сборке командой `npm run images`.
